# Weighted channel shares

Tags: `tags_v12_jobs.de_2024-08_2025-04.post.jsonl`. Share = weighted share of all postings (flagged or not) with the channel as tag. 95% intervals from 1000 bootstrap draws inside each day. Unflagged and invalid-answer postings count as none (0 invalid answers). Values in per cent.

Days with postings in a window can be fewer than the window length (the corpus ends in September 2026). A window with a few hundred postings gives wide intervals: read the interval, not the point change.
