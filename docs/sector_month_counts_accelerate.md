# Sector-month counts around the primary events (Month 3, step 1)

Rule: a sector is usable for an event in a source only if its estimated number of postings is at least **100** in every pre-window month and every post-window month (event month left out). A description counts as text from 200 characters. Estimates come from page samples (see the script's header for limits); `!` = below the minimum, `~` = the 95% interval straddles the minimum. Only the first sector tag of a posting is used, duplicates are not removed, so the counts are optimistic upper bounds.
